# 横屏手游 HUD 验证

## 本次修改

- Ability `orientation=landscape`，窗口同时请求 `Orientation.LANDSCAPE`。
- 新增 `LandscapeHud.ets`，替换原来居中堆叠的品牌、速度表、分数板、工具栏和镜头栏。
- 左上紧凑速度、档位、鱼分、里程、成就、时刻；右上镜头/设置/暂停/更多。
- 镜头与附加工具默认折叠，点击展开；中央保留角色及道路视野。
- 左下虚拟摇杆：左右转向、上推加速、下拉刹车，支持死区、拇指反馈及触点 ID 跟踪。
- 右下圆形技能键：金色大跳跃键，青色展翅与按铃键。
- 暂停、弹窗、后台或组件销毁时清除摇杆输入，避免卡键。
- 默认追随镜头；深链指定镜头仍优先。

## 验证环境与结果

- Pura90 HarmonyOS API 24 模拟器，HDC `127.0.0.1:5633`。
- Hvigor `assembleHap` 成功，使用当前工程官方签名配置覆盖安装成功。
- 最终系统截图为 **2856 × 1320 横屏**。
- 已目视确认：HUD 不再重叠、右侧动作键完整可见、中央主角无遮挡、原对角线半屏问题未复现。
- 跳跃及展翅按钮触发后成就数变化；鱼分和里程持续更新。
- 已注入摇杆长按与滑动。完整双指并发手势未做自动化测试。
- 暂停按钮切换后 UI tree 显示“继续”，点击可恢复。
- 镜头菜单展开正常；后台 Home 再恢复后进程保持。
- 最终安装版本 PID 检查通过。
